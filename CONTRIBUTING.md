# Contributing to RadioGrid

Thanks for wanting to help. Bug reports, stations that stopped working and
ideas are welcome as GitHub issues. Code pull requests aren't accepted for
now; describe the change in an issue instead, and we'll write it ourselves.

The RadioGrid, RadioGridXL and MarshWorks names and logos aren't covered by
the GPL. A fork is welcome; give it its own name and mark.
